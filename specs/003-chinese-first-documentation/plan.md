# 003 中文优先文档——实现计划

状态：已实现

## 实现思路

先在根目录指导中建立中文优先规则，再把 SDD 说明、模板和既有规格整体翻译为中文。
技术标识、命令和专有名词保留原文，以免影响复制执行和机器校验。

扩展标准库 SDD 校验器：把中文状态映射到既有规范化状态，并同时接受
`## 验证方式` 与历史 `## Verification` 标题。为兼容已有外部或临时规格，英文状态
继续有效，但仓库模板默认只生成中文。

MIT 许可证的官方英文文本保持不变，另增非官方中文参考译本，并在 README 中说明
两者关系。

## 涉及文件

- `AGENTS.md`：翻译仓库级指导并增加中文优先约束。
- `README.md`：将 SDD 标题和流程说明中文化，补充文档语言与许可证说明。
- `specs/README.md`：翻译 SDD 工作流与约定。
- `specs/_template/`：提供默认中文规格、计划和任务模板。
- `specs/001-sft-learning-sop/`：翻译既有 SFT 基线规格。
- `specs/002-codex-native-sdd/`：翻译既有 SDD 初始化规格。
- `specs/003-chinese-first-documentation/`：记录本次文档语言改造。
- `src/sft_sop/*.py`：翻译代码文档字符串和面向用户的命令行提示。
- `src/sft_sop/check_sdd.py`：支持中文状态、章节名和中文结果提示。
- `tests/test_sdd.py`：覆盖中文格式与英文状态兼容。
- `pyproject.toml`：将项目说明改为中文。
- `LICENSE.zh-CN.md`：增加 MIT 许可证非官方中文参考译本。

## 关键决策

- “中文为主”是正文语言约定，不要求翻译代码和机器可读标识。
- 保留英文状态兼容性，避免破坏现有用户自建规格；仓库模板改用中文状态。
- 不改写 `LICENSE`，避免非官方翻译替代有法律效力的原文。
- 不增加按字符比例判断语言的脆弱校验；通过仓库指导、中文模板和审阅来约束正文语言。

## 风险与缓解

- 风险：翻译技术术语后难以对应代码或生态文档。
  - 缓解：首次出现时保留英文术语，命令和标识始终使用原文。
- 风险：状态翻译导致 SDD 校验失效。
  - 缓解：统一映射为内部规范化状态，并增加中英文格式测试。
- 风险：中文许可证被误认为法律原文。
  - 缓解：在译文顶部突出非官方声明，并链接英文 `LICENSE`。
- 风险：大范围文档改动意外夹带本机信息。
  - 缓解：提交前执行隐私关键词和绝对路径扫描。
